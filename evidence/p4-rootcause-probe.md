# P4 阶段01 实测证据：近重复去重的根因是页面动态浮层（非阈值）

- 时间：2026-10-23 12:00 – 14:00
- 目标：P3 登记的 P4 候选①「恢复感知去重收益」——用户指令「做 P4（去重收益恢复）」
- 结论先行：**原目标的前提不成立**。收益不是被我的安全阈值削掉，而是**"重复帧"根本不是重复**——是 WPS「快捷登录并查看」浮层里的动态头像/动画每帧都在变。真正的解法是**在渲染期剥离浮层**，让去重阈值恢复分辨力。

## 1. 复现 P3 的现象

P3 加固后（uniform 守卫 + 逐格否决），真实序列的丢弃数：

| 序列 | 丢弃数 |
|---|---|
| P2 素材包 45 帧（settle=700） | **0** |
| P3 实抓 20 帧（settle=2500） | **0** |

而 P3 加固**前**的首版在 50 屏序列里曾丢 4 张。表面看是"我的阈值太严把收益削掉了"。

## 2. 逐对量特征：不可分（三种采样都试过）

真实素材：P2 素材包 45 张（`C:\deepseek网页抓取\…-3.shots`）。分组：
- **真重复/近似**（应判重）：`28vs30`、`28vs32`、`29vs30`、`30vs32`
- **必须保留**（内容不同）：`26vs27`、`38vs42`、`41vs43`、`28vs44`、`01vs02`、`25vs26`

| 采样 | 真重复对 | 必须保留对 | 可分？ |
|---|---|---|---|
| 32×32 点采样（现用） | `28vs30` MAD=3.08 / k=29 / fill=0.08 / area=0.337 | `38vs42` MAD=**2.79** / k=27 / fill=0.08 / area=0.317 | ✗ 重叠（保留的反而更小） |
| 8×8 块采样 | `28vs30` meanBlock=**2.807** | `38vs42` meanBlock=**2.424** | ✗ 重叠 |
| 4×4 块采样 | `28vs30` meanBlock=2.905 | `38vs42` meanBlock=2.512 | ✗ 重叠 |
| 逐格否决 / bbox 居中度 / 填充率 / 面积占比 | 全部重叠 | 全部重叠 | ✗ |

**结论**：在"该判重的对"与"该保留的对"之间，**所有像素特征都统计重叠** → 这不是阈值问题。

## 3. 真因：页面自己的动态覆盖层

DOM 探针（`workorders/probe-popup.mjs`）在 kdocs 页面查到：

| 元素 | class | rect |
|---|---|---|
| 浮层容器 | `component-popup component-login-modal-pop` | (0, 0, 1376, 809) —— 覆盖整个 body |
| 登录面板 | `wps-login-panel__body` | (509, 246, 358, 202) |
| 标题 | `wlcp-guide__title` | (632, 246, 112, 24) —— "快捷登录并查看" |

该浮层内含**动态头像/动画**，每帧像素都不同 → 它把帧间差异的分布整个抹平：
- 同内容帧之间：MAD 3~36（浮层噪声主导）
- 不同内容帧之间：MAD 2.2~6.4（**比同内容帧还小**，因为后者浮层噪声更大）

另注：32×32 **点采样会放大微小差异**——`27vs28` 只差 2 个像素，采样点恰好命中那 2 点 → maxCell=113、MAD=36.8。

## 4. 解法验证：渲染期剥离浮层

探针 `workorders/probe-p4-strip.mjs`：每屏截图前从 DOM 移除覆盖型浮层，再截图。

| 项 | 结果 |
|---|---|
| 剥离命中 | 首帧 `removed=4`（容器+面板+标题+遮罩），其后 `removed=0`（**页面不重建浮层**，剥离一次即长期有效） |
| 剥离后相邻帧差异 | 12 帧**全部真不同**：MAD 7.4~52.2、maxCell 237~255 → 去重判定**正确地不判重** |
| 剥离前后对比 | 剥离前"同内容对" MAD≈3（浮层噪声）；剥离后同内容若真相同会趋近 0 → **双阈值（maxCell≤24 且 MAD≤1.5）重新具备分辨力** |

结论：**不动去重算法，改为先剥离浮层**——去重的安全阈值即可恢复作用，且不再有"内容被误删"的风险（内容变化仍会被逐格否决拦下）。

## 5. 剥离启发式（四重约束，缺一不剥）

| 约束 | 取值 | 理由 |
|---|---|---|
| class 关键词 | `popup｜modal｜mask｜overlay｜dialog｜guide`（忽略大小写） | 覆盖层命名惯例；命中即候选 |
| 覆盖面积 | ≥ 85% 视口面积 | 局部浮层（工具提示、悬浮卡）不动 |
| 自身文本量 | < 300 字 | 防止误剥正文容器（大段文字） |
| 标签 | 非 `CANVAS` / `IFRAME` | 正文渲染载体绝不能动 |

实测命中 4 个元素，正是目标浮层；正文容器（canvas）未被触碰。
